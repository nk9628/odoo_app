Vertical Statusbar Widget

Visual approval workflow tracker for Odoo

Module Overview

The Vertical Statusbar Widget is a custom Odoo component that provides a visual representation of approval stages or workflow steps. It displays a vertical timeline with clear indicators for completed, active, and pending stages.

This widget is perfect for tracking document approval processes, project milestones, sales pipelines, or any multi-step workflow where users need a clear visual indication of progress.

Implementation Guide

How to Implement

1

Define the Selection Field

Create a selection field in your Odoo model with the stages of your workflow.

2

Add the Widget to Your View

Use the widget="vertical_state" attribute on your field in the XML view.

3

Optional Sidebar Placement

Wrap the field in a oe_form_sidebar_vertical_stage div for automatic right sidebar positioning.

Real Implementation Example

XML View Integration Code

<record id="view_order_form_inherit_remaining_fields" model="ir.ui.view">
    <field name="name">sale_order.form.inherit.remaining.fields</field>
    <field name="model">sale_order</field>
    <field name="inherit_id" ref="sale.view_order_form"/>
    <field name="arch" type="xml">
        <xpath expr="//sheet" position="after">
            <div class="oe_form_sidebar_vertical_stage">
                <field name="state" widget="vertical_state" />
            </div>
        </xpath>
    </field>
</record>

Implementation Notes:

  • The widget is placed in the sidebar using oe_form_sidebar_vertical_stage class
  • It uses the existing state field with widget="vertical_state"
  • Positioned after the main form sheet using XPath
  • Automatically adapts to Odoo's responsive layout
